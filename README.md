Exchange-Tracker

Exchange-Tracker is a modern, web-based currency converter and analytics tool that provides real-time exchange rates, interactive visualizations, and smart predictive insights for over 80 global currencies.
Designed with a sleek dark/light interface, it offers a seamless experience for travelers, traders, and finance enthusiasts seeking reliable currency data and trend projections.
 Features
 Instant Currency Conversion — Convert between 80+ world currencies in real time.
 Interactive Line Charts — Visualize exchange rate trends with Chart.js.
 Dark/Light Theme Support — Switch easily between elegant modes.
 Predictive Insights — Get intelligent rate projections based on past performance.
 Historical Data Visualization — Explore past currency movement trends.
 Responsive Design — Fully optimized for desktop, tablet, and mobile devices.

Technology	Purpose
HTML5 ->	Structure and layout
CSS3  ->	Styling and theming (dark/light mode)
JavaScript ->	Core logic, chart handling, and interactivity
Chart.js ->	Dynamic and interactive currency charts

How It Works
1.Enter the amount you want to convert.
2.Select the source currency and the target currency.
3.Click Convert to get real-time results.
4.View exchange rate trends and market projections on the chart.
